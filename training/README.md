# OA-LoRA Training

This directory contains the training implementation for the proposed OA-LoRA framework.

The training pipeline supports:

- Stable Diffusion XL (SDXL) 1.0
- Low-Rank Adaptation (LoRA)
- Occlusion-aware adaptation
- Prior preservation
- Adaptive Synthetic Data Scheduling (ASDS)
- TuSimple and CULane datasets

The training configuration files are provided in the `configs/` directory.
Dataset preparation and loading scripts are provided in the `datasets/` directory.
